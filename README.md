# Infinity Faucet
Web estática lista para GitHub Pages.

Archivos:
- index.html
- style.css
- script.js

Antes de publicar, reemplaza `TU_ENLACE_DE_AFILIADO_1` ... `TU_ENLACE_DE_AFILIADO_10` por tus enlaces reales y cambia los nombres/descripciones/recompensas.

GitHub Pages:
1. Crea un repositorio.
2. Sube los 3 archivos a la raíz.
3. Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main / root.
6. Save.
